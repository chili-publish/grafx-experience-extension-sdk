# Contributing to the project

Welcome! To ensure a smooth workflow and consistent codebase, please review the following standards before submitting a Pull Request.

For general project information and setup instructions, please refer to the [README](README.md) file.

## Documentation

Generate the API reference locally using the [TypeDoc instructions](README.md#local-api-reference). Customer-facing getting started lives on [docs.chiligrafx.com](https://docs.chiligrafx.com/GraFx-Developers/grafx-experience/extension-sdk/).

## Releases

Versioning and npm publishes use Changesets. Typical feature flow (changeset → optional canary → merge → Version Packages): [docs/releasing.md](docs/releasing.md).

## 🤖 AI Agents

If you are an AI agent working on this codebase check the AI.md file to get valuable information about the project and your behavior.
